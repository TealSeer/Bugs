# Bugs

[![CI](https://github.com/TealSeer/Bugs/actions/workflows/ci.yml/badge.svg)](https://github.com/TealSeer/Bugs/actions/workflows/ci.yml)

This is a simulator of sorts, the "bugs" are dots that live, reproduce, and die. As they reproduce, the color of the dot can "mutate" up or down in the R/G/B channels, leading to cool effects.
